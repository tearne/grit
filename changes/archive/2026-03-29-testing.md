# Testing

## Intent

Establish a test suite for `grit` covering the core session logic: diff computation, state persistence, blob hash comparison, and reviewed-stable determination. These are the parts most likely to regress silently, and they can be exercised without a terminal.

## Approach

**Test targets** (all in `session.rs`):
- `session_id` — ref name sanitisation and joining
- `merge_state` — reviewed-stable survives matching blob hashes, resets on mismatch, new files arrive as unreviewed, removed files are dropped
- `Session::save` + `load_persisted` — round-trip persistence to `state.toml`

**Test infrastructure**: private functions are exposed via `#[cfg(test)] pub(crate) mod test_support` in `session.rs`, per the style guide. Tests live in `mod tests` at the bottom of the same file.

**Dependencies**: `tempfile` added as a dev-dependency for temporary directories in persistence tests.

**Out of scope**: `compute_diff_files` (requires a real git repo with commits) and TUI rendering (requires a terminal). Both are better suited to integration tests in a future change.

**Review cadence**: end of change.
